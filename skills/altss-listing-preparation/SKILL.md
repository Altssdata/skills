# Prepare an Altss listing request

Use when a firm wants to submit its public profile, discuss Enhanced visibility or correct a listed profile. This workflow prepares material for Altss review; it does not create or publish a profile.

Read https://altss.com/why-submit and https://altss.com/submit for the current listing options, eligibility, scope and terms. Use the live offer rather than remembered prices. Basic submission, a factual correction and an Enhanced enquiry have different purposes. Ask which is intended only when the user's request does not establish it.

Collect the firm's public name, official website, proposed public description, the submitter's business contact information and their authority to submit it. Include the existing canonical profile URL and supporting primary sources for a correction. Distinguish a legal entity from a brand or similarly named firm. Collect only information needed for the request; keep private contact details out of the proposed public description.

Prepare copyable plain-text email to contact@altss.com with a subject identifying the firm and request type. Separate the proposed public profile text, evidence links, requested changes and private review contact. Do not invent missing fields. For Enhanced, state the requested scope and unresolved questions for the team; an enquiry is not an accepted order.

The website opens a prefilled draft in the visitor's email app; the visitor must press Send. Preparing or opening that draft is not delivery. Preserve the full copyable text if a mail client is absent or truncates a long draft. Send only when the user explicitly authorizes sending to Altss through an available email tool, and report its actual delivery acknowledgement separately.

Altss reviews the text manually and sends a Stripe payment link after agreeing Enhanced scope. Do not invent a payment link, collect card details, claim payment or promise publication, search-engine indexing or ranking. Follow a verified payment link only with the purchaser's authorization. Factual corrections do not require an Enhanced purchase.

A removal request from a third party does not authorize deleting, unpublishing or deindexing a profile. Prepare the accuracy correction and supporting evidence for review while retaining the canonical URL.
